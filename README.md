# 🌍 Geolocation, Google Maps y Leaflet en Ionic Angular

Este proyecto muestra cómo integrar **ubicación en tiempo real** dentro de aplicaciones **Ionic Angular**, utilizando la **Geolocation API de Capacitor** y diferentes librerías de mapas como **Google Maps** y **Leaflet**.

---

## 📌 1. Geolocation API (Capacitor)

La **Geolocation API** de Capacitor permite obtener la posición actual del dispositivo (latitud, longitud, precisión, altitud, velocidad, etc.).

### Instalación
```bash
npm install @capacitor/geolocation
npx cap sync
